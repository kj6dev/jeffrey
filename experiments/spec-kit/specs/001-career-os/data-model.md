# Three-file state contract

Context.md: career direction; constraints; current goals and allocations; standing facts with dates when mutable; manually supplied dated external references; separately labeled assessments and unknowns. Never copy current Context into behavior instructions.

Active Work.md: one heading per attention case, concise description, source reference, current engagement recommendation, next action, closure condition. Under the same heading retain each open commitment and real due date if applicable. Unknown timing remains explicit. Relationship context stays local where relevant. A case may start/end immediately or remain awaiting a decision; no mandatory state machine.

Outcome Log.md: selective dated entries with observed result and source, separate assessment and material limits. Optional initial expectation and actual result for a small sample. A completed case has zero or one useful entry as needed, not an automatic history record.

Validation: retained cases have required fields; unresolved promises cannot disappear on event completion. Sources reference artifacts instead of copying them. Changing/closing a promise requires specific supplied evidence or user disposition. No separate decision/person records. No automatic pruning of open obligations to meet maintenance limits.
