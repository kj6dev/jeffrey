# Future capabilities — parking lot

These ideas were discovered during design. They are **not roadmap commitments**.

A capability moves out of this file only when v0 usage supplies evidence that it solves recurring friction or a repeated opportunity.

## Candidate sensors

- Slack sensing for direct asks, relevant discussions, and shared AI "watering holes"
- email follow-up/commitment sensing
- calendar context and meeting preparation triggers
- repo/PR activity summaries
- agent-session summaries
- company/org/team initiative context
- lightweight peer-pattern sensing from public work behavior

## Candidate reasoning specializations

- mentor / 1:1 preparation
- unfamiliar-code review
- RFC/document engagement depth
- presentation preparation
- opportunity evaluation
- new-tool / new-tech bounded comparison
- repeated AI-generated-code failure detection

## Candidate derived views

- weekly project/work summary
- biweekly written standup
- monthly/quarterly career update
- promotion-evidence narrative
- learning-frontier view
- market-capability-gap view
- relationship/meeting brief

Derived views should be regenerated from canonical state rather than becoming new sources of truth.

## Candidate external calibration

A personal job-posting pipeline may export a dated, sanitized market reference:
- recurring qualifications
- rising capabilities
- differentiators
- target-role signals
- credible gaps

The work-side runtime should not need raw job postings or active job-search state.

## Candidate passive pattern discovery

Historical personal agent chats may be mined for recurring cognitive transformations such as:
- fuzzy idea -> clarified project/spec
- unfamiliar code -> sufficient understanding to decide
- ambiguous problem -> decomposition/investigation plan
- project activity -> durable status/context
- new tool -> adoption decision
- rough implementation -> critique/quality improvement

Do not assume a repeated topic is a reusable workflow. Discover stable transformations empirically.

## Explicitly deferred

- autonomous communication
- autonomous task scheduling
- life-management features
- complex agent graphs
- vector database
- custom UI
- automatic public/private data export
- mandatory Spec Kit/SPDD/BMAD/Spec Kitty runtime
